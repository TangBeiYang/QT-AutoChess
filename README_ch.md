# Project A — Synera：自走棋

一款基于 Qt Widgets 与 C++17 开发的自走棋游戏，支持实时战斗、装备与合成系统、羁绊机制、经济运营，以及 JSON 存档读档。

---

# 快速开始

## 编译与运行

```bash
# 使用 CMake 构建
cmake --build build-mingw

# 运行可执行文件
./build-mingw/ProjectAQtBoard.exe
```

## 系统需求

* CMake 3.16+
* Qt6（兼容 Qt5 Widgets）
* 支持 C++17 的编译器（MinGW / MSVC）
* Windows 10 / 11

---

# 游戏简介

## 游戏目标

玩家需要在有限回合内，通过运营经济、购买单位、搭配羁绊与装备来击败所有敌人波次。

核心玩法包括：

1. 从商店购买单位
2. 将单位部署到棋盘
3. 通过三个相同单位进行升星
4. 为单位配置装备
5. 自动进行实时战斗
6. 根据不同难度完成全部波次挑战

## 三种难度模式

| 模式   | 回合数   | 初始生命 | 初始金币 |
| ---- | ----- | ---- | ---- |
| 极速模式 | 8 回合  | 40   | 20   |
| 标准模式 | 10 回合 | 60   | 15   |
| 困难模式 | 13 回合 | 80   | 12   |

新建存档后会进入难度选择界面：

* 极速模式（8 回合）
* 标准模式（10 回合）
* 困难模式（13 回合）
* 返回

该 GUI 与主菜单、读取存档界面保持统一布局与配色风格。

# 核心系统

# 单位系统

游戏当前包含 17 个命名单位，分为：

* 战士
* 坦克
* 弓箭手
* 法师
* 刺客（插件职业）
* 辅助（插件职业）

## 主职业

| 职业  | 图标 | 定位     |
| --- | -- | ------ |
| 战士  | ●  | 均衡近战   |
| 坦克  | ■  | 前排承伤   |
| 弓箭手 | ★  | 远程持续输出 |
| 法师  | ✚  | 范围法术输出 |

## 插件职业

| 职业 | 图标 | 定位           |
| -- | -- | ------------ |
| 刺客 | ▼  | 切后排          |
| 辅助 | ◆  | 治疗 / 增益 / 削弱 |

## 升星系统

三个相同单位可以合成为更高星级单位：

* 1 星 → 2 星
* 2 星 → 3 星

属性成长倍率：

* 1 星：1.0×
* 2 星：1.8×
* 3 星：3.2×

提升属性包括：

* HP
* ATK
* 防御
* 魔抗

# 羁绊系统

# 商店与经济系统

## 部署位系统

* 初始部署位：3
* 最大部署位：6

升级花费：

| 当前 → 目标 | 金币 |
| ------- | -- |
| 3 → 4   | 4  |
| 4 → 5   | 6  |
| 5 → 6   | 8  |

## 商店等级

* 初始等级：1
* 最高等级：4

不同等级决定可刷出的单位费用。

| 商店等级 | 可出现单位 |
| ---- | ----- |
| 1    | 2 费   |
| 2    | 3 费   |
| 3    | 4 费   |
| 4    | 5 费   |

升级花费：

| 当前 → 目标 | 金币 |
| ------- | -- |
| 1 → 2   | 5  |
| 2 → 3   | 7  |
| 3 → 4   | 10 |

## 减价机制

部署位与商店等级升级共享减价规则：

* 若本回合未升级
* 下回合该升级项花费 -1
* 最低降至原价 50%（向上取整）

## 每回合收入

* 基础收入：4 金币
* 胜利：+3 金币
* 失败：+1 金币
* 无连胜/连败奖励

# 战斗系统

## 实时自动战斗

游戏采用 60 FPS 实时战斗。

单位状态包括：

* 待命
* 移动
* 攻击
* 施法
* 死亡

## AI 行为

* 近战单位自动追击最近敌人
* 远程单位保持射程输出
* 辅助优先治疗最低生命友军
* 刺客开局切入后排

## 失败扣血机制

不同难度拥有不同失败伤害区间与成长规则。

失败伤害 = 基础伤害 + 敌方存活单位星级伤害。
